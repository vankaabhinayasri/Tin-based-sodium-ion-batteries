Sn-Based Sodium-Ion Battery Anodes

Optimisation of Sn Based Anodes for Sodium Ion Batteries Using Machine
Learning and Physics Based Modelling

B.Tech Project --- Department of Mechanical Engineering, IIT Indore

Overview

This project combines literature-mined data, machine learning for
long-term capacity retention, and 2D COMSOL modelling of Na+ transport
and electrode response.

Current Status

95 valid long-term-cyclability observations

29 independent studies

18 ML predictors

Random Forest baseline with LOO-CV

Baseline 2D Sn-Na COMSOL model

Preliminary SOC, concentration and potential results
